# little factory
a factory management/automation game revolving around a tiny player where you have to get the resources from the input tile to the output tile, with a certain input and output. also you get the resources from the map and you can take damage and do damage to enemies.
## how to contribute
always use PRs and use the following guidelines
- `patch:` for small fixes
- `feature:` for new features
- `release:` for software-breaking changes
### make your PRs small
Please make them easy to review and commit small changes.
## that's it!
thanks for contributing!
